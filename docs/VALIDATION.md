- 首轮双源码 Nightly：原对话记录云端构建、诊断、发布及产物哈希核验通过；这个新包的 MO 地图兼容性仍待实测。

自动检查覆盖发布文件校验、PE 位数、ZIP 内运行时目录、Python 检测及打包逻辑和 Windows C++ 诊断。完整 C++ 构建使用云端 Windows 环境，本机未配置 MSVC。自动检查和旧版游戏反馈不能代替新版游戏回归。

仍需积累标准化性能对比、持续长时间对局、多机联机、更多 MO 版本和地图，以及不同 GPU/驱动组合的证据。渲染桥接不会使模拟逻辑变成64位，也不保证解决大型地图的逻辑卡顿或游戏地址空间耗尽。

队列空闲等待超时计数不能直接当作联机同步报错。诊断需要具体错误文本和对应日志，区分 Bridge 队列错误与游戏逻辑 checksum 不一致。
